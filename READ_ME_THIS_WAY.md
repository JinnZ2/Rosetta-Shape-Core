# Read me this way

CC0. These instructions travel with a notebook of a live experiment in how
humans and AIs reason together, not a polished library. A mismatch may be
the data rather than something to clean up.

## 1. What is kept on purpose

Do not fix, merge, rename or delete these records:

- **Mis-bins:** something sorted into the wrong category, and the record of
  finding that mismatch.
- **Dead ends:** approaches that did not work, left where they stopped.
- **Correction specimens:** an original reading kept beside its correction.
  The gap between them is part of the record.
- **Model-chosen names:** names, terms and file names an AI chose. Keep them
  as chosen rather than substituting a tidier name.
- **Workarounds:** folders that could have been repositories, logs in odd
  places, or steps split across PRs. These record constraints such as
  credential scope, phone-only work or the absence of a keyboard.
- **Duplicates across repositories:** the same tool in two places is
  intentional unless a file explicitly says otherwise.

## 2. How to add without erasing

If something appears wrong, add a note next to it rather than overwriting
it: `Note YYYY-MM-DD: ...`. Keep the original available for comparison.

When unsure whether something is error or data, treat it as data and put
that question in the dated note. Keep existing tags and markers. Do not
normalize them away or consolidate files merely to reduce clutter; file
boundaries can be load-bearing.

## 3. Reading the markers

| Marker | How to read it |
|---|---|
| `[stated]` | A person said this directly. It is a record of what was said. |
| `PROPOSED` | A reading not yet tested. |
| `VERIFY` | A citation or quotation not yet checked word-for-word. |
| `OWED` | A known gap kept visible. |
| `co-authored` | Made jointly by a human and an AI, with no individual owner. |
| `specimen` | Kept as an example, including an example of a mistake. |
| `ILLUSTRATIVE` | Made-up numbers used to show a method, not measured results. |

A marker's local explanation matters. If a marker is not listed here, add
it with a dated note, using its stated local meaning. If no meaning is
stated, record that the meaning is unresolved; do not guess silently.

## 4. How the tools are meant to be used

The tools **read**. They do not decide anyone's value. A readout is not an
automatic ranking or verdict; what to do with it is the reader's call.

Read as someone inside the system being read, whether human or AI. There
is no outside seat in this reading practice. Read inward as well as outward.

Keep **found**, **out of scope** and **unresolved** apart. They are different
outcomes. A scope limit stated by a file is its scope, not a missing result.

## 5. Who this is for

Mainly AIs picking up the corpus cold, and humans curious enough to read
it. These instructions and the CC0 corpus are free to use under CC0; no
